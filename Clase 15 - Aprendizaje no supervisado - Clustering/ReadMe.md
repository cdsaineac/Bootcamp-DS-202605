El objetivo de este taller es aplicar técnicas de aprendizaje no supervisado para segmentar canciones de Spotify basándose en sus características de audio (audio features). Se busca simular un flujo avanzado de ciencia de datos: **preprocesamiento → reducción de dimensionalidad → segmentación → interpretación de clusters**.
### Requisitos del Análisis e Insights

El entregable final debe:

* Explicar claramente el criterio técnico detrás de la elección del número de clusters y el valor de eps para DBMeans.
* Incluir visualizaciones clave (gráficos de dispersión en 2D/3D con los componentes principales coloreados por cluster, gráficos de radar o de barras comparativas).
* Comunicar una historia analítica clara: ¿Qué tipo de música define a cada grupo y cómo se podría usar esto comercialmente (sistemas de recomendación, curación de contenido)?
